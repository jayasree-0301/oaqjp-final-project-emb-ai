# Emotion Detection Web Application using Flask

Project Overview

This project is an emotion detection web application developed as the final graded project of a Coursera course with the help of AI focused on developing applications using Python and Flask.

The application takes a text input from the user and analyzes it to identify different emotions expressed in the text. The detected emotions are processed and formatted to provide a clear and meaningful output.

The project also focuses on testing and validating the application through unit testing, packaging, error handling, and other software development practices.

Emotion Detection

The application analyzes the input text and identifies emotions such as:

- Anger
- Disgust
- Fear
- Joy
- Sadness

The emotion detection results are processed to determine the overall emotion expressed in the given text.

Key Features

- Accepts text input from the user
- Detects multiple emotions from the input
- Processes emotion scores
- Formats the output in a readable manner
- Identifies the dominant emotion
- Provides error handling for invalid or empty input
- Includes unit testing
- Includes packaging and module testing
- Uses Flask to provide a web interface
